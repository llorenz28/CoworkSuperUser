# Historical query setup

The saved-query instructions previously published here applied only to the
archived report editions retained under `src/`. Those editions are not the
current public release and are not supported by `CoworkSuperUser.pbit`.

For the current release, do not create or enter Viva Insights Person Query,
Consumption Query, or partition identifiers. Follow the supported dashboard
export workflow instead:

1. Open **[aka.ms/copilotdashboard](https://aka.ms/copilotdashboard)**.
2. Go to **Consumption Dashboard** > **Explore Cowork** > **Export data**.
3. Choose **Export by week**.
4. Follow the current [`SETUP.md`](../SETUP.md) instructions to load the two
   exported CSV files through `DataFolder`.

See [Detailed setup](SETUP.md) for access requirements and data handling.
