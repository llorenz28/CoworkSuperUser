# Attribution

CoworkSuperUser reuses and adapts public Microsoft patterns and assets from:

- [microsoft/Cowork-Adoption-Intelligence](https://github.com/microsoft/Cowork-Adoption-Intelligence)
- [microsoft/DecodingSuperUsage](https://github.com/microsoft/DecodingSuperUsage)

The interpretation storyboard follows the operating-guide structure of the Cowork Adoption Intelligence V4 interpretation storyboard. The saved-query connector setup and Analytics Hub discovery pattern are informed by DecodingSuperUsage.

All cited repositories were public Microsoft releases when this version was prepared. CoworkSuperUser's report logic, Viva query integration, validation tooling, documentation, and release packaging are maintained in this repository.
