# CoworkSuperUser walkthrough transcript

The template contains no embedded customer data. Public images use deterministic fabricated data.

## CoworkSuperUser

Meet CoworkSuperUser: a public, data-free Power BI template that turns approved Viva Insights results into a clear adoption story. It connects observed reach, repeat use, habit movement, consumption, potential champions, and work-pattern context without turning usage into a performance score.

## Start Here

Start Here routes program owners to the right question. Is adoption building momentum? Who is returning? Where is usage sustained? How do work patterns differ? Begin with the decision, then open the page carrying the right evidence and boundary.

## Executive Adoption

Executive Adoption summarizes the selected population. Active users show observed reach. Power and Habitual stages show sustained use. Latest weekly active rate shows the newest aligned week, while function comparisons show where enablement may need local attention.

## Weekly Adoption & Usage

Weekly Adoption and Usage separates reach from recurrence and intensity. Switch views without clearing filters, then compare active rate, return rate, cohorts, sessions, and credits. Use exact values before relative color, and check rollout timing and coverage before calling a trend.

## Adoption by Attributes

Adoption by Attributes compares observed reach and sustained-use share across function, organization, or level. Check population and privacy first, then compare the group with the company benchmark. Treat the result as a program signal, never an employee-performance comparison.

## Habit Movement

Habit Movement compares previous and latest available-history stages. Read improved, stable, declined, and sustained retention together. Interpret every change with its stage, then use department views to locate differences. New history or organizational change can also move classifications.

## Champion Identification

Champion Identification finds an outreach starting point among sustained users. Global order uses active weeks, then average weekly sessions. Department coverage reveals gaps. These are potential peer-enablement partners, not experts, top performers, or automatic candidates for personnel action.

## Sessions and Credits

Sessions and Credits keeps frequency and resource consumption explicit. Read total sessions, total credits, sessions per active person, and credits per session. Switch between Overall and By department, and expand to pseudonymous IDs only when authorized. Neither measure proves value.

## Work Pattern Context

Work Pattern Context compares supplied Viva Insights patterns across Cowork stages and time. Network and beyond-hours metrics appear only when supplied. The Non-user group is a descriptive reference, not a control group. Cowork use can coexist with a difference without causing it.

## Methods and Metric Guide

Methods and Metric Guide defines each measure's source, calculation, grain, direction, caveat, and evidence class. Use it before quoting results or thresholds. A correct calculation can still be unsuitable when its denominator, privacy state, or evidence class is omitted.

## Two completed queries. Two setup paths.

Setup starts with two completed Viva Insights analyses in one partition. Build a weekly Person Query with organization and work-pattern fields. Build a Cowork consumption query with sessions, credits, and policy context. Choose connector-only or faster export-assisted setup, then validate.

## One report. A clearer Cowork adoption story.

That is CoworkSuperUser: one public report experience for reach, return, stages, consumption, potential champions, and work-pattern context. Choose the connection option that fits, build the two approved queries, review the guide, and turn evidence into an owned enablement action.
